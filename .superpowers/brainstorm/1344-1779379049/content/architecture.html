System Architecture

Three independent layers — each with one job

LAYER 1 — DATA

Node.js API Server

Express.js on port 3001

  • GET /api/live — real-time S&P 500 price
  • GET /api/historical — 5 years OHLCV data

Uses: yahoo-finance2, express

→
LAYER 2 — AI + STORAGE

Python: LSTM + SQLite

Fetches from Node.js, stores + predicts

  • SQLite: historical_data table
  • SQLite: predictions table
  • LSTM model → 30-day forecast

Uses: tensorflow/keras, sqlite3, requests

→
LAYER 3 — UI

Streamlit Dashboard

Reads from SQLite, displays everything

  • Live price + daily change
  • Historical price chart
  • 30-day LSTM forecast overlay

Uses: streamlit, plotly, pandas
